# 기기 검증 요약

아래는 **유구한컷 1.1.3**의 정식 빌드로 수행한 실기기 회귀 검사 요약입니다. 검사 수는 자동 확인 항목의 수이며, 서로 다른 사용자 기능의 수나 모든 상황에서의 무결성을 뜻하지 않습니다.

## 확인한 기기

| 검사일 | 기기 | Android | 통과 항목 | 주요 범위 |
| --- | --- | --- | ---: | --- |
| 2026-10-21 | Galaxy S9 · SM-G960N | 10 | 127 | 촬영·저장·추가 항목·프로·짧은 FHD 영상·화면 여백 |
| 2026-10-22 | Samsung 폴더블 · SM-F976N | 17 | 711 | 외부·내부 화면, 촬영 옵션, 화면 여백, 실제 접기·펼치기 |

제품명 추정 대신 기기에서 확인한 모델 번호를 기록했습니다. 검사 과정에서 기존 앱을 삭제하거나 기록을 초기화하지 않았습니다.

## 촬영과 기록

사진은 실제 JPEG 저장과 디코딩을 확인했습니다. 기본 단계·추가 항목·프로 촬영의 자동 번호, 추가 항목 이름 변경 후 연결 유지, 사진 삭제 후 사진 수 갱신과 사용 번호 유지도 확인했습니다. 프로 모드는 요청한 ISO와 노출에 대한 저장 사진의 EXIF를 확인했습니다.

동영상은 무음 FHD 영상을 저장하고 프레임을 디코딩했습니다. 폴더블의 두 화면에서는 기기가 제공한 야간·인물·얼굴 보정을 전후면으로 검사했습니다. 기기가 제공하지 않은 확장 모드는 검사하지 않았으며 삼성 기본 카메라와 같은 화질을 보장하는 결과도 아닙니다.

## 화면과 접기 전환

세로·가로 화면, 키보드 표시·해제, 시스템 바와 노치 여백을 확인했습니다. 폴더블에서는 사용자가 직접 접고 펼치는 동안 다음 흐름을 통과했습니다.

1. 내부 화면에서 사진 001 저장 후 녹화 시작.
2. 접은 뒤 외부 화면에서 약 21초의 유효한 FHD 영상 보존 확인.
3. 외부 화면에서 사진 002 저장.
4. 다시 펼친 내부 화면에서 사진 003 저장, 다음 번호 004 유지 확인.

이 결과는 녹화 파일 보존과 후속 촬영을 확인한 것입니다. 접는 동안 영상·음성의 무중단 연속성이나 앱 강제 종료 후 복구를 검증한 것은 아닙니다.

## 검증 범위의 한계

장시간 녹화·발열·마이크·음질·4K·반복 접기 내구성·현장 GPS 및 방위 정확도는 이번 버전 검사에 포함하지 않았습니다. 폴더블 검사 기기의 페이지 크기는 4KB였으므로 16KB 런타임 검증도 아닙니다.

같은 빌드의 로컬 정식 APK를 검사했으며 Google Play가 생성한 분할 APK, 심사·배포 상태, 다른 기종의 동작까지 확인한 결과로 확대하지 않습니다. 촬영에는 검사 전용 기록을 사용했고 기존 사용자 자료와 설정은 보존했습니다.
