# 기기 검증 요약

**문서 기준: 1.1.5 / 2026-11-04.** 버전과 실제 검사한 빌드를 구분해 기록합니다. 검사 수는 자동 확인 항목의 수이며, 서로 다른 사용자 기능의 수나 모든 상황에서의 무결성을 뜻하지 않습니다.

## 1.1.5 · Galaxy S9

**Galaxy S9 · SM-G960N / Android 10**에서 별도 패키지의 **1.1.5 테스트 APK**를 검사했습니다. 이 결과는 난독화한 정식 APK나 Google Play 서명 1.1.5의 기기 검증이 아닙니다.

| 검사 | 결과 |
| --- | --- |
| Java 호스트 자체 검사 | 317항목 통과 |
| release/debug/테스트 APK 빌드와 Lint | 빌드 통과, Lint 오류 0개·경고 있음 |
| 릴리스 APK/AAB·서명 등 출시 파일 검사 | 65항목 통과 |

| S9 유구 목록·현장 도구 UI 검사 | 80항목 통과 |
| S9 기기 검사 합계 | **356항목 통과** |
| 정식 APK·Play 서명 1.1.5 기기 검사 | 미완료 |

### 확인한 동작

- 유구 하나씩·여러 개 추가, 중복 이름 선택, 목록 전환, 유적별 목록과 다음 번호 유지, 재실행 후 복원.
- 저장 중 유구 전환 차단, 빈 비활성 유구 삭제·재추가 후 번호 유지, 사진이 있는 유구의 목록 삭제 제한.
- 표본/시굴 기본 항목, 새 파일명과 기존 코드 파일 인식, 항목 이름 편집 후 사진 연결·진행표·번호 유지.
- 실제 JPEG 4장 저장·디코딩, 프로 JPEG의 ISO 200·노출 1/125초, 약 3.9초의 무음 FHD 영상 저장·프레임 디코딩.
- 사진 메모·분류 정정·같은 구도 재촬영·원본 사진과 CSV의 ZIP 내보내기. 분류 정정 후 JPEG 원본 보존.

검사에는 전용 QA 기록을 사용했습니다. 기존 정식 앱을 제거·초기화하지 않았고, 기존 공용 JPEG 2장의 이름과 SHA-256이 검사 전후 같음을 확인했습니다. 이를 실제 사용자 기록 전체의 이전·복구 검증으로 확대하지 않습니다.

### 남은 범위

정식 APK·Play 서명 1.1.5의 실제 설치·실행, 폴더블 최신 버전 재검사, 장시간 녹화·발열은 미검증입니다. 마이크·음질·4K·현장 방위 정확도·16KB 런타임도 이번 결과에 포함하지 않습니다. 로컬 빌드·출시 파일 검사는 Play 심사·배포 완료를 뜻하지 않습니다.

### 촬영과 기록

사진은 실제 JPEG 저장과 디코딩을 확인했습니다. 기본 단계·추가 항목·프로 촬영의 자동 번호, 추가 항목 이름 변경 후 연결 유지, 사진 삭제 후 사진 수 갱신과 사용 번호 유지도 확인했습니다. 프로 모드는 요청한 ISO와 노출에 대한 저장 사진의 EXIF를 확인했습니다.

동영상은 무음 FHD 영상을 저장하고 프레임을 디코딩했습니다. 폴더블의 두 화면에서는 기기가 제공한 야간·인물·얼굴 보정을 전후면으로 검사했습니다. 기기가 제공하지 않은 확장 모드는 검사하지 않았으며 삼성 기본 카메라와 같은 화질을 보장하는 결과도 아닙니다.

### 화면과 접기 전환

세로·가로 화면, 키보드 표시·해제, 시스템 바와 노치 여백을 확인했습니다. 폴더블에서는 사용자가 직접 접고 펼치는 동안 다음 흐름을 통과했습니다.

1. 내부 화면에서 사진 001 저장 후 녹화 시작.
2. 접은 뒤 외부 화면에서 약 21초의 유효한 FHD 영상 보존 확인.
3. 외부 화면에서 사진 002 저장.
4. 다시 펼친 내부 화면에서 사진 003 저장, 다음 번호 004 유지 확인.

이 결과는 녹화 파일 보존과 후속 촬영을 확인한 것입니다. 접는 동안 영상·음성의 무중단 연속성이나 앱 강제 종료 후 복구를 검증한 것은 아닙니다.

### 당시 검증 범위의 한계

장시간 녹화·발열·마이크·음질·4K·반복 접기 내구성·현장 GPS 및 방위 정확도는 이번 버전 검사에 포함하지 않았습니다. 폴더블 검사 기기의 페이지 크기는 4KB였으므로 16KB 런타임 검증도 아닙니다.

같은 빌드의 로컬 정식 APK를 검사했으며 Google Play가 생성한 분할 APK, 심사·배포 상태, 다른 기종의 동작까지 확인한 결과로 확대하지 않습니다. 촬영에는 검사 전용 기록을 사용했고 기존 사용자 자료와 설정은 보존했습니다.
