# 기능 안내

유구한컷은 유적·유구별 사진을 촬영하면서 파일명과 조사 항목을 함께 정리하는 Android 카메라 앱입니다. Android 8.0 이상을 지원하며, 카메라 기능은 기기의 공개 지원 범위에 따라 달라집니다.

## 촬영과 자동 파일명

유적명과 유구명을 입력하고 촬영 항목을 고르면 번호가 자동으로 붙습니다. 방위 기록을 켠 경우 파일명에 방향도 표시합니다.

```text
현장A--수혈1호 001 조사전 남→북.jpg
```

같은 유적·유구의 기본 단계와 추가 항목은 사진 번호를 함께 사용합니다. 사진을 삭제해도 앱이 보관한 사용 번호는 재사용하지 않습니다. 촬영 전 번호를 예약하므로 저장 실패나 중단 후 번호가 건너뛸 수 있습니다. 앱 데이터 삭제·재설치로 예약 기록이 사라지면 남아 있는 사진을 기준으로 번호를 다시 계산합니다.

## 필요한 조사 항목 추가

기본 항목은 **조사전·토층·조사중·조사후**입니다. `+ 편집`에서 출토유물·내부시설·내부수혈·내부주혈 등 현장에 필요한 항목을 만들고, 이름이나 버튼 표시 여부를 바꿀 수 있습니다. 추가 항목의 고정 식별자로 기존 사진을 연결하므로 이름을 바꿔도 사진과 집계가 유지됩니다.

단계의 색상과 사진 수는 **접근 가능한 사진의 존재 여부**를 뜻하며 조사 완료 판정이 아닙니다. 진행표의 `0/4`~`4/4`는 기본 네 단계에 사진이 있는지를 집계하며, 추가 항목은 별도 사진 수로 표시합니다. 갤러리에서 삭제한 뒤 돌아오면 현황을 다시 확인합니다. 파일명을 바꾸거나 사진 접근을 제한하면 집계가 달라질 수 있습니다.

## 촬영 도우미와 현장 기록

- 사진·동영상·프로 모드, 전후면 전환, 줌, 초점, 노출, 타이머, 격자선과 수평계를 제공합니다. ISO·셔터 속도·초점·화이트밸런스 및 야간·인물 등 확장은 기기 지원 범위에 따릅니다.
- 같은 구도 재촬영은 기존 사진을 반투명 참고 화면으로 겹칩니다. 새 사진에 합성하지 않으며 자동 위치 정합 기능은 아닙니다.
- 유구별 진행표, 사진 메모, 분류 정정과 변경 이력을 관리하고 원본 사진·CSV 목록을 ZIP으로 내보낼 수 있습니다. 영상은 사진 번호와 단계별 사진 수에 포함되지 않습니다.

## 기록 보관과 위치

로그인·광고·앱 자체 서버 업로드 없이 기기에서 사용합니다. 메모·계획·이력은 앱 삭제 시 사라지므로 필요한 자료를 내보내세요. 자동 가져오기는 지원하지 않습니다.

방위와 GPS는 기본적으로 꺼져 있습니다. GPS를 켜고 위치를 얻으면 사진에 위치가 저장될 수 있습니다. 센서값은 측량을 대신하지 않습니다. 사진과 내보내기 자료에는 위치·메모·이력이 포함될 수 있으므로 공유 전에 확인하세요. 외부 갤러리·백업 서비스의 동작은 해당 앱 설정에 따릅니다.
