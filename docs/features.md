# 기능 안내

유구한컷은 유적·유구별 사진을 촬영하면서 파일명과 조사 항목을 함께 정리하는 Android 카메라 앱입니다. **1.1.6 기준**이며 Android 8.0 이상을 지원합니다. 카메라 기능은 기기의 공개 지원 범위에 따라 달라집니다.

## 유적과 조사 유형

선택한 유적이 없으면 최초 설정에서 유적 이름과 조사 유형을 정합니다. 등록한 유적은 상단 목록에서 전환하며, 사용 중인 유적이 있으면 재실행할 때 설정 창을 반복해서 띄우지 않습니다. 유적별 마지막 유구와 선택한 촬영 항목을 기억합니다.

| 조사 유형 | 기본 촬영 항목 |
| --- | --- |
| 표본/시굴 | 트렌치전경 · 토층전경 · 토층세부 · 트렌치내유구 |
| 정밀발굴 | 조사전 · 토층 · 조사중 · 조사후 |

유적을 목록에서 삭제해도 사진·동영상·메모·사용한 사진 번호는 지우지 않습니다. 목록 정리와 촬영 자료 삭제는 별도 동작입니다.

## 유구 목록과 사진 현황

촬영 화면 상단의 **유구명 또는 화살표**를 누르면 유구 목록이 열립니다. 유구를 하나씩 또는 여러 개 추가하고, 목록 행을 눌러 바로 촬영 대상을 바꿉니다. 같은 이름을 다시 선택해도 목록이 중복되지 않으며, 서로 다른 유적의 유구는 따로 관리합니다.

설정에 있던 **유구별 조사 진행표**를 이 목록으로 옮겼습니다. 유구별 촬영 항목과 사진 수를 확인하면서 선택할 수 있습니다. 기존 어두운 화면과 금색 강조, 초록색 사진 상태 표시를 유지합니다.

현재 선택하지 않은 유구 중 앱에서 확인할 수 있는 사진이 없는 유구는 목록에서 삭제할 수 있습니다. 메모나 사용한 번호를 지우는 기능은 아니며, 같은 이름을 다시 추가해도 예약된 번호를 이어갑니다.

## 검색·정렬·즐겨찾기

유구 목록의 검색창에 이름을 입력하면 일치하는 유구를 찾습니다. 검색어와 미촬영 필터를 함께 사용할 수 있고, 목록에서 고른 유구로 바로 촬영을 이어갑니다.

| 정렬 기준 | 사용하는 기록 |
| --- | --- |
| 이름순 | 가나다와 이름 안의 숫자 순서. 예: 2호 → 10호 |
| 생성일순 | 목록에 만든 날짜. 이전 유구는 확인 가능한 첫 사진 날짜로 보완 |
| 사진 수순 | 앱에서 확인 가능한 사진 수 |
| 최근 촬영순 | 확인 가능한 사진 중 가장 최근 촬영 날짜. 영상 제외 |
| 미촬영 항목순 | 현재 진행표에서 사진이 없는 촬영 항목 수 |
| 최근 선택순 | 목록에서 유구를 선택한 시각. 같은 유구를 다시 선택해도 갱신 |
| 최근 기록 수정순 | 사진 메모를 실제로 바꾸거나 분류 정정을 완료한 시각 |

모든 기준에서 오름차순·내림차순을 선택합니다. 날짜 기록이 없으면 각 그룹 뒤에 표시하며, 같은 값은 이름순으로 정리합니다. 미촬영 항목 수는 실제 조사 완료 여부를 판단하는 값이 아닙니다. 최근 기록 수정에는 별표 변경·유구 선택·같은 메모 재저장·실패하거나 취소한 정정을 포함하지 않습니다.

유구의 **☆/★**를 누르면 즐겨찾기를 바꿉니다. 별표만 눌러서는 촬영 대상이 바뀌지 않습니다. 정렬 메뉴의 **즐겨찾기 상단 고정**은 기본 켜짐이며, 즐겨찾기 그룹을 먼저 놓고 각 그룹 안에서 선택한 기준으로 정렬합니다. 고정을 꺼도 별표는 유지됩니다. 검색·미촬영 필터는 즐겨찾기에도 적용됩니다.

즐겨찾기와 선택·수정 시각은 유적별로 관리합니다. 정렬 기준·방향·상단 고정 설정은 앱을 다시 열어도 유지합니다. 폴더블에서 열린 목록·정렬 메뉴를 접거나 펼칠 때 화면에 맞게 패널 크기를 조정합니다.

## 촬영과 자동 파일명

유적명과 유구명을 입력하고 촬영 항목을 고르면 번호가 자동으로 붙습니다. 방위 기록을 켠 경우 파일명에 방향도 표시합니다.

```text
현장A--수혈1호 001 조사전 남→북.jpg
현장A--트렌치1 001 [토층전경] 남→북.jpg
```

같은 유적·유구의 기본 단계와 추가 항목은 사진 번호를 함께 사용합니다. 사진을 삭제해도 앱이 보관한 사용 번호는 재사용하지 않습니다. 촬영 전 번호를 예약하므로 저장 실패나 중단 후 번호가 건너뛸 수 있습니다. 앱 데이터 삭제·재설치로 예약 기록이 사라지면 남아 있는 사진을 기준으로 번호를 다시 계산합니다.

**1.1.5부터 추가 항목은 읽기 쉬운 이름을 대괄호로 묶어 저장합니다.** 이전 파일명의 `[c_…]`는 항목을 구분하는 내부 식별 코드였으며 사진 손상을 뜻하지 않습니다. 새 사진·동영상에는 이 코드가 드러나지 않고, 기존 네 기본 단계의 파일명 규칙은 유지합니다.

기존 코드 형식도 계속 읽으며, 이미 저장한 사진을 자동으로 개명하지 않습니다. 앱은 분류 ID와 이전 항목 이름의 연결 정보를 보관하므로 이름을 편집한 뒤에도 기존 사진을 연결합니다. 새 형식은 이전 앱에서 인식하지 못할 수 있어 함께 쓰는 기기를 1.1.5 이상으로 맞춰야 합니다. 파일만 다른 기기로 복사하거나 앱 설정을 잃으면, 이름이 바뀐 항목의 과거 사진을 원래 분류로 연결하는 것까지 보장하지 않습니다.

## 필요한 조사 항목 추가

`+ 편집`에서 출토유물·내부시설·내부수혈·내부주혈 등 유적별로 필요한 항목을 만들고, 이름이나 버튼 표시 여부를 바꿀 수 있습니다. 항목의 분류 ID와 이전 이름의 연결 정보는 앱 안에 보관합니다.

단계의 색상과 사진 수는 **접근 가능한 사진의 존재 여부**를 뜻하며 조사 완료 판정이 아닙니다. 표본/시굴은 표시 중인 촬영 항목을, 정밀발굴은 기본 네 단계를 기준으로 현황을 보여 주며 추가 항목의 사진 수도 확인할 수 있습니다. 갤러리에서 삭제한 뒤 돌아오면 현황을 다시 확인합니다. 파일명을 임의로 바꾸거나 사진 접근을 제한하면 집계가 달라질 수 있습니다.

## 촬영 도우미와 현장 기록

- 사진·동영상·프로 모드, 전후면 전환, 줌, 초점, 노출, 타이머, 격자선과 수평계를 제공합니다. ISO·셔터 속도·초점·화이트밸런스 및 야간·인물 등 확장은 기기 지원 범위에 따릅니다.
- 같은 구도 재촬영은 기존 사진을 반투명 참고 화면으로 겹칩니다. 새 사진에 합성하지 않으며 자동 위치 정합 기능은 아닙니다.
- 유구별 진행표, 사진 메모, 분류 정정과 변경 이력을 관리하고 원본 사진·CSV 목록을 ZIP으로 내보낼 수 있습니다. 영상은 사진 번호와 단계별 사진 수에 포함되지 않습니다.

## 기록 보관과 위치

로그인·광고·앱 자체 서버 업로드 없이 기기에서 사용합니다. 메모·계획·이력은 앱 삭제 시 사라지므로 필요한 자료를 내보내세요. 자동 가져오기는 지원하지 않습니다.

방위와 GPS는 기본적으로 꺼져 있습니다. 방향은 기기 센서로 구하며, 위치 정보는 진북 보정과 사진 위치 기록에 사용될 수 있습니다. 센서값은 측량을 대신하지 않습니다. 사진과 내보내기 자료에는 위치·메모·이력이 포함될 수 있으므로 공유 전에 확인하세요. 외부 갤러리·백업 서비스의 동작은 해당 앱 설정에 따릅니다.
