# 업데이트 기록

앱에 적용한 변경을 정리합니다. 이 문서는 Google Play의 공개 배포·심사 완료 상태를 뜻하지 않습니다. 현재 확인한 기기와 검사 범위는 [기기 검증 요약](testing.md)을 참고하세요.

## 1.1.3

화면 호환성과 정식 빌드의 코드 최적화를 개선했습니다.

- R8 코드 최적화·축소·난독화와 리소스 축소를 적용했습니다.
- 오래된 AndroidX Fragment 의존성을 1.1.0에서 1.9.1로 갱신했습니다.
- 시스템 바·카메라 구멍·키보드에 조작 버튼이 가려지지 않도록 화면 여백을 처리하고 회전 시 다시 계산하도록 개선했습니다.
- 기존 사진·촬영 항목·번호 예약·메모의 저장 형식을 유지했습니다.

2026년 10월 21일 Galaxy S9, 10월 22일 Samsung 폴더블의 내부·외부 화면과 실제 접기·펼치기에서 검증했습니다. 폴더블 검사에 따라 제품 빌드를 추가로 변경하지는 않았습니다. 긴 영상 녹화나 모든 기기의 동작을 검증한 결과는 아닙니다.

## 1.1.2

기본 네 조사 단계 외에 현장별 추가 촬영 항목을 정식 앱에서 관리할 수 있도록 확장했습니다.

- 출토유물·내부시설·내부수혈·내부주혈 등 필요한 항목을 직접 추가할 수 있습니다.
- 추가 항목의 이름을 바꾸거나 버튼을 숨길 수 있습니다. 고정 식별자로 기존 사진과 집계를 유지합니다.
- 기본 단계와 추가 항목은 같은 유적·유구의 사진 번호를 공유합니다. 삭제한 사진의 사용 번호는 되돌리지 않습니다.
- 갤러리 필터·메모·분류 정정·내보내기에 추가 항목을 연결하고 진행표에 추가 사진 수를 별도로 표시합니다.

단계 표시는 사진 유무를 기준으로 하며 조사 완료를 판정하지 않습니다. 추가 항목의 사용 방법과 번호 규칙은 [기능 안내](features.md)에서 확인할 수 있습니다.
