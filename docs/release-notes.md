# 업데이트 기록

앱에 적용한 변경을 정리합니다. 이 문서는 Google Play의 공개 배포·심사 완료 상태를 뜻하지 않습니다. 현재 확인한 기기와 검사 범위는 [기기 검증 요약](testing.md)을 참고하세요.

## 1.1.6

많은 유구에서 촬영 대상을 찾기 쉽도록 검색·정렬·즐겨찾기를 추가하고 폴더블의 목록 표시를 개선했습니다.

- 유구 목록에서 이름을 검색할 수 있습니다.
- 이름·생성일·사진 수·최근 촬영·미촬영 항목·최근 선택·최근 기록 수정의 7가지 기준과 오름차순·내림차순 정렬을 제공합니다.
- 유적별 즐겨찾기와 목록 상단 고정을 지원합니다. 검색·미촬영 필터와 함께 사용할 수 있습니다.
- 정렬 기준·방향·상단 고정 설정을 재실행 뒤에도 유지합니다.
- 폴더블에서 목록이나 정렬 메뉴를 연 채 접거나 펼칠 때 이전 화면 폭을 유지해 잘리던 문제를 수정했습니다.
- 새 정렬 기록을 저장하면서 기존 사진·메모·이력과 사용한 번호 예약을 보존합니다.

2026-11-09 S9의 최종 1.1.6 별도 테스트 앱에서 자동 단언 806회, 호스트 자체 검사 375항목과 출시 파일 검사 65항목을 통과했습니다. 배포용 서명 AAB를 빌드·검증했으며 이 작업에서 Play 업로드·출시는 진행하지 않았습니다. 정식 APK·Play 서명 앱의 실기 검증과 최종 1.1.6 폴더블 검사는 별도 범위입니다.

## 1.1.5

촬영 대상 선택과 사진 현황 확인을 유구 목록으로 모으고, 파일명에 노출되던 내부 코드를 정리했습니다.

- 상단 유구명이나 화살표를 누르면 유구 목록이 열립니다. 하나씩 또는 여러 개 추가하고, 목록에서 선택해 바로 촬영합니다.
- 설정의 유구별 조사 진행표를 유구 목록으로 옮겼습니다. 기존 어두운 화면과 금색·초록색 상태 표시를 유지합니다.
- 유적별 마지막 선택과 사용한 번호를 이어갑니다. 사진이 없는 비활성 유구는 목록에서 삭제할 수 있으며, 같은 이름을 재추가해도 번호 예약을 보존합니다.
- 새 추가 항목 파일명의 `[c_…]` 내부 식별 코드를 없애고, `[토층전경]`처럼 항목 이름을 표시합니다. 동영상에도 같은 표시 규칙을 적용합니다.
- 기존 코드 형식의 사진도 계속 읽습니다. 이미 저장한 사진은 자동 개명하지 않으며, 앱에 보관한 이전 이름 연결 정보로 항목 이름 편집 후에도 사진을 연결합니다.

파일명 예: `현장A--트렌치1 001 [토층전경] 남→북.jpg`

함께 사용하는 기기는 1.1.5 이상으로 맞춰 주세요. 파일만 옮기거나 앱 설정을 잃은 경우의 분류 연결 한계는 [기능 안내](features.md)에 설명했습니다. 2026-11-04 당시 S9 별도 테스트 앱에서 자동 확인 356항목을 통과했습니다. 당시 정식 APK·Play 서명 1.1.5의 기기 검증과 폴더블 재검사는 미완료였으며, 이후 결과는 버전별로 구분합니다.

## 1.1.4

여러 유적과 조사 유형을 선택해 촬영할 수 있도록 현장 설정을 확장했습니다.

- 유적 최초 설정과 유적 목록을 추가하고, 유적별 마지막 유구와 선택 항목을 기억합니다.
- 표본/시굴은 **트렌치전경·토층전경·토층세부·트렌치내유구**, 정밀발굴은 **조사전·토층·조사중·조사후**를 기본 항목으로 제공합니다.
- 촬영 항목의 추가·이름 편집·숨김을 유적별로 관리하고, 조사 유형에 맞는 진행표와 CSV 목록을 제공합니다.
- 유적 목록에서 삭제할 수 있도록 했습니다. 촬영 자료·메모·이력·사용한 번호는 보존하고, 삭제한 목록 항목은 재실행 후 다시 나타나지 않게 했습니다.
- 표본/시굴의 이전 기본 항목 이름은 한 번만 갱신하며, 사용자가 편집한 이름과 기존 JPEG는 유지합니다.

## 1.1.3

화면 호환성과 정식 빌드의 코드 최적화를 개선했습니다.

- R8 코드 최적화·축소·난독화와 리소스 축소를 적용했습니다.
- 오래된 AndroidX Fragment 의존성을 1.1.0에서 1.9.1로 갱신했습니다.
- 시스템 바·카메라 구멍·키보드에 조작 버튼이 가려지지 않도록 화면 여백을 처리하고 회전 시 다시 계산하도록 개선했습니다.
- 기존 사진·촬영 항목·번호 예약·메모의 저장 형식을 유지했습니다.

2026년 10월 21일 Galaxy S9, 10월 22일 Samsung 폴더블의 내부·외부 화면과 실제 접기·펼치기에서 검증했습니다. 폴더블 검사에 따라 제품 빌드를 추가로 변경하지는 않았습니다. 긴 영상 녹화나 모든 기기의 동작을 검증한 결과는 아닙니다.

## 1.1.2

기본 네 조사 단계 외에 현장별 추가 촬영 항목을 정식 앱에서 관리할 수 있도록 확장했습니다.

- 출토유물·내부시설·내부수혈·내부주혈 등 필요한 항목을 직접 추가할 수 있습니다.
- 추가 항목의 이름을 바꾸거나 버튼을 숨길 수 있습니다. 고정 식별자로 기존 사진과 집계를 유지합니다.
- 기본 단계와 추가 항목은 같은 유적·유구의 사진 번호를 공유합니다. 삭제한 사진의 사용 번호는 되돌리지 않습니다.
- 갤러리 필터·메모·분류 정정·내보내기에 추가 항목을 연결하고 진행표에 추가 사진 수를 별도로 표시합니다.

단계 표시는 사진 유무를 기준으로 하며 조사 완료를 판정하지 않습니다. 추가 항목의 사용 방법과 번호 규칙은 [기능 안내](features.md)에서 확인할 수 있습니다.
